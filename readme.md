# Gemini Chatbot

A simple conversational AI chatbot powered by Google Gemini and the `google-genai` SDK.

## Setup

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Configure API Key:**
   Ensure your API key is in `chatbot.env` (or `.env`):
   ```env
   YOUR_API_KEY="your_api_key_here"
   ```

## Running the Chatbot

To start the chatbot, run:
```bash
python chatbot.py
```

- Type your question and press **Enter**.
- Type `exit` to end the conversation.
